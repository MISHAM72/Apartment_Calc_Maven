# Руководство для контрибьюторов

Добро пожаловать в проект **Apartment_Calc_Maven**! Мы ценим ваш интерес и готовы принять ваш вклад. Это руководство поможет вам внести изменения правильно и эффективно.

---

## Как внести вклад?

1. **Форкните репозиторий**  
   Перейдите на страницу проекта по адресу [Apartment_Calc_Maven](https://github.com/MISHAM72/Apartment_Calc_Maven) и нажмите кнопку **Fork** в верхнем правом углу.

2. **Склонируйте ваш форк к локальной машине**  
   Используйте следующую команду:
   ```bash
   git clone https://github.com/ВАШЕ_ИМЯ_ПОЛЬЗОВАТЕЛЯ/Apartment_Calc_Maven.git
   ```
   Замените `ВАШЕ_ИМЯ_ПОЛЬЗОВАТЕЛЯ` на имя вашего аккаунта GitHub.

3. **Создайте новую ветку для ваших изменений**  
   Разделите изменения по веткам, чтобы они были логически независимыми:
   ```bash
   git checkout -b feature/my_changes
   ```

4. **Внесите изменения в код**
    - Убедитесь, что ваш код хорошо структурирован и документирован.
    - Соблюдайте стиль кода, который уже используется в проекте.

5. **Запустите тесты**  
   Убедитесь, что все тесты проходят успешно и ваши изменения не ломают встроенную функциональность. Если проект содержит тестовую среду, дополнительные инструкции должны быть в файле `README.md` или в этом документе.

6. **Закоммитьте изменения**  
   Используйте понятные и описательные сообщения для коммитов:
   ```bash
   git commit -m "Добавил расчет коммунальных услуг"
   ```

7. **Отправьте изменения в свой форк**  
   После завершения работы отправьте изменения на ваш удалённый репозиторий:
   ```bash
   git push origin feature/my_changes
   ```

8. **Создайте Pull Request**  
   Перейдите в [оригинальный репозиторий](https://github.com/MISHAM72/Apartment_Calc_Maven) и нажмите **New Pull Request**. Обязательно заполните описание изменений, укажите причину изменений и, при необходимости, ссылку на соответствующее **Issue**.

## Общие сведения о проекте

### Основные разделы

- **`src/main/java`** — основной код Java.
- **`src/test/java`** — модульные тесты.
- **`pom.xml`** — конфигурация Maven.

---

## Требования к коду

1. Все изменения должны быть написаны на **Java**.
2. Придерживайтесь [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html) для поддержания единообразного стиля.
3. Документируйте основные методы, классы и функции.
4. Если исправляете баг:
    - Создайте Issue на странице проекта [Issues](https://github.com/MISHAM72/Apartment_Calc_Maven/issues) — это упростит отслеживание.
    - Укажите номер Issue в описании к вашему **Pull Request** (например: `Fixes #123`).

---

## Правила именования веток

Применяйте следующие соглашения:

- Для новых функций: `feature/описание-функции`
- Для исправления багов: `bugfix/описание-исправления`
- Для изменений в документации: `docs/описание-документа`

Примеры:
- `feature/add-rent-calculation`
- `bugfix/fix-tax-rounding`
- `docs/update-readme`

---

## Как работают тесты?

Для запуска тестов выполните в корне проекта следующую команду Maven:
```bash
mvn test
```
Убедитесь, что до отправки изменений все тесты выполняются успешно.

## Как сообщить об ошибке?

Если вы нашли баг, создайте новое [Issue](https://github.com/MISHAM72/Apartment_Calc_Maven/issues) в репозитории с описанием проблемы. Пожалуйста, включите следующую информацию:
- Описание проблемы.
- Шаги для воспроизведения.
- Ожидаемое поведение.
- Ваша среда разработки (например: ОС, версия Java, версия Maven).
